> 제약(절대): **인쇄와 모바일오더 주문은 절대 문제 일으키지 않는다.** 검증·작업 모두 생명선 무접촉.
> 검증 엔진 = docs/SYSTEM_VERIFICATION_METHOD.md (이 이니셔티브의 Phase 0). Irene 선택: **"증거 먼저"**.

## 0. 안정적으로 "느껴지는" 5요소 (경쟁 POS 가 투자한 것)
1. **누르면 즉시 반응** — 손대는 순간 눌림 표시. (우리: 터치 후 색 굳음·한 박자 지연)
2. **멈춘 듯 안 보임** — 항상 "불러오는 중" 표시, 빈/굳은 화면 0. (우리: 느린 와이파이에 굳음)
3. **어딜 가도 똑같이 생김** — 버튼·표·팝업 전 화면 동일. (우리: 화면마다 미묘 차이)
4. **에러를 손님처럼 안 보여줌** — 빨간 경고/크래시 0, 조용히 처리.
5. **안 흔들림** — 글자·칸 안 튐, 안정된 격자.

## 1. 단계별 할 일 (구체)

### Phase 0 — 증거 만들기 (지금 선택됨, 느낌→데이터)
- [ ] 검증 엔진 구축(SYSTEM_VERIFICATION_METHOD.md L2~L5). 안전계약 §0 준수.
- [ ] **체감품질 스캔(L5)** 핫스크린(POS·플로어플랜·결제·KDS)에 → **"어설픈 순간 Top 20"** 목록(탭지연·레이아웃튐·로딩없음·콘솔에러·컴포넌트불일치·터치타겟).
- [ ] **흐름·카오스(L2/L3)** 루프 실행 → 전체 주문·인쇄상태·단계이동의 간헐 race/분실/중복 목록.
- [ ] 산출물 = 우선순위 매긴 결함 백로그(큰 것부터). 이 Phase 까지가 "증거 먼저".

### Phase 1 — 매일 만지는 화면부터 끝까지 (체감 변화 최대)
대상: POS Terminal · Floor Plan · 결제 · KDS (직원이 종일 만지는 것).
- [ ] **즉각 반응**: 모든 누를 수 있는 요소에 눌림 표시(전역) + 터치 후 색 굳음 제거(@media hover/:active, 전역 1곳).
- [ ] **멈춤 없음**: 데이터 대기 = 로딩/스켈레톤 표준, 빈상태 = 텍스트(DataTableEmpty). 굳은 흰 화면 0.
- [ ] **눌러놓고 뒤에서 저장**(낙관적): 주문 생성·품목 추가·단계 이동·결제 핫패스에서 화면 즉시 반영 + 실패 시 조용한 롤백/안내. 느린 와이파이에도 안 기다림. **(인쇄 트리거·상태는 무변경 — 화면 반응만)**
- [ ] **에러 처리 통일**: alert()/raw 에러 잔재 제거 → 인라인/표준 안내.
- [ ] **모션 일관**: 빠르고 절제된 전환(과하지 않게).

### Phase 2 — 일관성 빗질 (이미 진행 중인 것 끝까지)
- [ ] RA 표준·공용 컴포넌트(DataTable/Button/IconButton/StatCard/Modal/Select) 를 전 역할·전 화면에. 로컬 styled 잔재 교체.
- [ ] 색/아이콘/간격 토큰 통일(디자인 단일기준 §RA). check-design-guard 확장으로 신규 위반 차단.

### Phase 3 — 다시 어설퍼지지 않게 (가드레일)
- [ ] 검증 엔진을 **배포 게이트**에 묶음(L0~L4 fail-closed).
- [ ] 체감품질(L5) 회귀도 잡게: 탭지연·레이아웃튐·로딩없음·컴포넌트불일치를 baseline 대비 신규 위반 차단.
- [ ] 핫스크린 실브라우저 mount + 흐름 루프를 상시.
