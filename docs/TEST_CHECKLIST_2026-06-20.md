## 1. 직원 PIN 로그인 (P1-4)

**어디:** 로그인 화면

- [ ] 로그인 화면에 **"직원 PIN"** 전환 버튼이 보인다
- [ ] 직원 PIN 모드 → **온스크린 숫자패드**(키보드 없이 탭)로 PIN 입력 → 로그인된다
- [ ] 공용 단말: 한 번 로그인한 매장을 **기억**해서 다음엔 PIN만 누르면 된다
- [ ] (보안) 틀린 PIN 을 여러 번 빠르게 입력하면 잠시 **차단**된다 (브루트포스 방지)

## 2. 현금관리 / 마감 (Cash-up) (P2-5 Phase 1+2)

**어디:** 사이드바 → **현금관리(Cash drawer & close)** → `/restaurant/<매장>/cash-up`

### 교대 마감 흐름 (3단계 위저드)
- [ ] **교대 시작**: 개시현금 입력(숫자패드). 직전 마감현금이 **자동 제시**되는지
- [ ] **카운트**: 수단별 실제 금액 입력 — 이때 **예상 금액은 안 보인다**(블라인드 카운트)
- [ ] **차이 공개**: Expected/Counted/Diff + "RM2 부족" 같은 평문 + 신호등 색
- [ ] **마감**: 마감현금이 **다음 교대 개시현금으로 자동 이월**되는지

### 인출/입금 (Cash in / out) — Phase 2 신규
- [ ] 카운트 단계에 **Cash in / Cash out** 버튼 → 표준 팝업(숫자패드 + 사유)
- [ ] 입금/출금 입력 후 → **순액(Net)** 이 표시되고, 마감 예상현금에 반영되는지
  - (현금 예상 = 개시 + 현금매출 + 입금 − 출금)

### Z-Report + 캐시드로어 — ⚠️ **실프린터 필요 (운영 배포 후)**
- [ ] 마감 후 **"Z-Report 인쇄"** → 빌 프린터로 마감 요약(매출·수단별·인출입금·차이·마감현금) **종이 출력**
- [ ] **"드로어 열기"** 버튼 → 실제 **캐시 서랍이 열리는지**
- [ ] (dev) 위 두 버튼이 화면에서 정상 동작(에러 없음)하는지까지는 dev 에서 확인 가능

### 권한
- [ ] 서빙 전용 직원(카운터 권한 없음)은 현금관리에 **접근/마감 불가**한지

## 3. 취소 사유 설정 (P1-3)

**어디:** 설정 → (주문/운영) 취소사유 + 라이브오더/플로어플랜에서 주문 취소

- [ ] 설정에서 취소사유를 **끔 / 선택 / 필수** 로 바꿀 수 있다
- [ ] **필수**로 두면 → 주문 취소 시 **사유 없이는 취소가 막힌다**
- [ ] 사유를 적으면 정상 취소된다

## 4. 예약 ↔ 플로어플랜 연결 (P2-6) + 예약-주문 루프

**어디:** 예약 화면(Reservations) + 플로어플랜 + 설정>예약

### 테이블 배정
- [ ] 예약 화면에서 예약에 **플로어플랜 테이블을 선택**해 배정할 수 있다 (번호 직접타이핑 아님)
- [ ] 새 예약 만들 때도 테이블을 골라 배정된다
- [ ] (방지) **같은 테이블 + 겹치는 시간**에 두 예약 → **이중예약 차단** 안내

### 플로어플랜 '예약됨' 표시
- [ ] 예약시간이 임박한 테이블(활성 주문 없음)이 플로어플랜에 **'예약됨'(연한 파랑)** + **"예약 7:00 PM"** 배지로 뜬다
- [ ] 이미 **주문 중인 테이블은 점유색이 우선**(예약색에 안 묻힘)
- [ ] 설정 → 예약 → **"Floor plan lead time"**(플로어 표시 리드타임, 기본 120분) 조절 → 표시 시점이 바뀐다

### 체크인 흐름 (손님 도착)
- [ ] 예약 화면에서 **"Arrived"(도착)** 누르면 → **플로어플랜으로 자동 이동 + 그 테이블 POS 자동 열림 + 인원수 자동 입력**
- [ ] 플로어플랜에서 '예약됨' 테이블 클릭 → 패널에 **게스트/인원/예약시간** + "Check in (New Order)" 버튼

### 예약-주문 루프 (자동 상태)
- [ ] 체크인한 테이블에서 **주문 생성** → 그 예약이 자동으로 **'착석(seated)'** 으로 바뀐다
- [ ] 그 주문 **결제 완료** → 예약이 자동으로 **'완료(completed)'** 로 바뀐다
- [ ] (방지) 예약 없는 워크인 주문은 미래 예약에 **잘못 연결되지 않는다**
