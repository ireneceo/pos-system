# Content Matrix — F&B 6 역할 × Pain Point 풀

> **목적**: `/글쓰기` 와 `/블로그초안` 의 주제 선정 + 영상/SNS 톤 결정 시 참조하는 단일 source of truth.
>
> **사용 시점**:
> - `/글쓰기` 3단계 (주제 3건 제안) — 매트릭스에서 셀 선택 또는 신규 추가
> - `/블로그초안` 1단계 (메타 확정) — persona 매칭
> - `/블로그초안` 5-A (video_prompt) — 카오스 시각 / 인터뷰 진실 참조
> - `/블로그초안` 5-B (social_post) — 톤 트랙 (카오스 vs 인터뷰) 결정
>
> **갱신**: 새 토픽 추가 시 이 표만 수정. 셀 늘리되 다 채울 필요 없음 (점진적 확장).

## 사이클 패턴 (2주 1회 운영, 카오스 2 : 인터뷰 1 비율)

```
[Week 1]  운영 카오스 (Reel A)
```

## 6 역할 × Pain Point 매트릭스 (30셀 풀)

각 셀 = 콘텐츠 1 사이클 시드. 한 줄 pain point는 CF copy 그대로 영상 텍스트 오버레이로 사용 가능.

### Restaurant Admin (단일 매장 사장 / RA)

| # | Pain Point (CF 한 줄) | 카오스 시각 (영상 0-8s) | 인터뷰 진실 (영상 0-8s, 다큐) |
|---|---|---|---|
| RA-1 | **사장이 멈칫하는 그 5초.** | 피크타임, 주문/직원/배달/결제 4개 동시 몰림, 사장 freeze + eye widen | "직원 문제인 줄 알았어요. 근데 시스템이 다 따로 놀고 있더라고요." |
| RA-2 | **마감 30분이 두 시간이 됐어요.** | 영업 종료 후 카드 매출 / 현금 / 배달 앱 / 쿠폰 따로 정산, 졸음, 야간 매장 | "정산 맞추다가 새벽 2시. 다음날 출근이 또 다가오죠." |
| RA-3 | **메뉴 한 번 바꾸면 4곳을 바꿔요.** | POS 화면 / 키오스크 / QR / 배달앱 4개 화면, 메뉴 가격 따로 입력 | "치킨 가격 RM1 올렸는데 배달앱은 옛날 가격. 손님이 화났어요." |
| RA-4 | **사장이 휴가 가면 영업이 안 돼요.** | 매장 빈 공간, 폐점 안내문, 직원 당황 | "결제 비밀번호도 제가 들고 있고, 정산도 제가 해야 하고…" |
| RA-5 | **모바일 주문이 들어와도 모르는 채로 30분.** | 손님 모바일 결제 → 카운터 직원 모름 → 30분 후 손님 항의 | "QR 켠 첫 주에 주문 5건이 그냥 묻혀 있었어요." |

### Brand General (프랜차이즈 본부 / BG)

| # | Pain Point | 카오스 시각 | 인터뷰 진실 |
|---|---|---|---|
| BG-1 | **5개 매장이 5개 회사처럼 돌아요.** | 본사 신메뉴 추가 → 가맹점 4곳 반영 / 1곳 옛 메뉴, 화면 split | "매장마다 가격이 다르게 찍히고 있더라고요." |
| BG-2 | **본사가 매장 매출을 일주일 늦게 봐요.** | 가맹점에서 엑셀로 보내옴, 본사 화면에 어제 데이터, 결재판 쌓임 | "본사인데 실시간으로 본 적이 없어요. 늘 주말에 합산." |
| BG-3 | **레시피 표준화? 매장마다 다르게 만들고 있어요.** | 매장 A 김치찌개 / 매장 B 김치찌개 비주얼 다름, 본사 매뉴얼 종이 한 장 | "같은 브랜드인데 다른 맛이 나요. 손님이 먼저 알아채요." |
| BG-4 | **신메뉴 출시했는데 30%만 팔아요.** | 본사 광고 vs 매장 POS 화면 — 신메뉴 비활성화, 직원 모름 | "프로모션은 시작됐는데 매장에서 활성화 안 했어요. 한 달 늦었어요." |
| BG-5 | **로열티 적립이 가맹점마다 따로 도네요.** | 손님 카드 / 매장1 적립 / 매장2 못 보임, 컴플레인 | "본사 카드를 만들었는데 정작 손님은 적립이 안 됐다고 환불 요청." |

## 영상 트랙 선택 가이드

### 운영 카오스 트랙 (Reel A/B/D)
- **선택 기준**: 셀의 카오스 시각이 시각적으로 강렬한 셀 (RA-1, RA-2, BG-1, FG-1 등)
- **톤**: 빠른 컷 / 시네마틱 / kinetic typography / 첫 1초 freeze hook
- **목표**: 공감 + 바이럴 + 기능 유입

### 현실 고백 인터뷰 트랙 (Reel C)
- **선택 기준**: 셀의 인터뷰 진실이 강한 셀 (RA-1 "직원 문제인 줄 알았어요", OW-1, SP-1 등)
- **톤**: 핸드헬드 / 다큐멘터리 / 자연 호흡 / 자막 강조
- **목표**: 브랜드 신뢰 + 시스템 구조 이해

## 참고

- 30셀 모두 채울 필요 X. 핵심 5-10셀로 시작 → 발행 후 반응 보고 확장
- pain point 한 줄은 영상 1.0-2.0s 텍스트 오버레이로 그대로 사용
- 인터뷰 진실은 따옴표 그대로 영상 voice-over 사용 가능
- 신규 cell 추가는 매장 인터뷰 또는 ContactInquiry/SupportTicket 데이터 기반 권장
