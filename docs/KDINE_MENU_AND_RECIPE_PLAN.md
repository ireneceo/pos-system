## 6. 시스템 제약 (알고 있어야 할 것)

1. **가격 예약 적용 기능이 없다.** 저장 즉시 손님 화면에 반영된다.
   단 `products.availability` 로 **노출 예약**(날짜·요일·시간)은 된다 — **손님 모바일 메뉴에만** 적용되고 POS 는 안 본다.
2. **메뉴 삭제는 하드 삭제** (`product.destroy()`, 소프트삭제 아님). 안 파는 메뉴는 **비활성**으로 두고 삭제는 나중에.
3. **변경 전 값이 안 남는다** — `activity_logs.changes` 가 menu_item update 27건 전부 `null`. 롤백 근거는 직접 뜬 스냅샷뿐.
4. **과거 매출은 안전하다** — `orders.order_items` 가 주문 시점 스냅샷(name·price·category)이고 리포트가 그걸 읽는다. 실측: 최근 200주문 345품목 **345/345** 스냅샷 보유.
5. **안전 작업창 = 현지 22:00 ~ 익일 09:00** — 최근 30일 주문 시각 실측상 그 시간대 주문 0건.
