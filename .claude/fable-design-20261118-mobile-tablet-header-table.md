## 3. 설계 — 공통 (한 번 고치면 전 화면)

### H. 폰 머리줄 (≤768)

지금: `☰ · 로고 · [기기] · ◐ · 종 · 지구 · DE` 한 줄(높이 80px 고정). ≤480 에서 매장 이름이 숨음.

**바꿈 — ≤480 은 같은 80px 안에서 두 줄:**
```
1줄(약 40px)  ☰   [로고]                 종⁴   🌐 KO   (DE)
2줄(32px)     ◐ FOODCOURT CENTRAL                         ▾     ← 줄 전체가 누름
```
- H1. **2줄 = 매장·역할 전환**: 화면 폭 전체, 왼쪽 정렬, 13px 굵게, 넘치면 말줄임. 이름이 다시 글자로 보인다(F2). 머리줄 높이 80px 은 그대로라 본문 위치는 안 바뀐다.
  - 구현 자리: 줄 모양은 `HeaderContextSwitcher.tsx`(보호 아님)의 폰 변형에서, 머리줄 안 세로 배치(위쪽 정렬·여백)만 MainLayout 의 `MobileHeader` 꾸밈 몇 줄(M3).
- H2. **언어 버튼에 «KO» 글자**: 2줄로 내려가 1줄에 자리가 생기므로 ≤480 에서도 지구 + 언어 코드(768 과 같은 모양). `LanguageSelector` 안.
- H3. **이름표**: ☰ «메뉴 열기» · 내 정보 «내 정보» · 언어 «언어» · 기기 칩 «이 기기의 POS 자리» — 4개 언어.
- H4. 481~768: 지금 한 줄 유지. 매장 이름 칸 최대 폭 140 → 600px 이상에서 220.
- H5. 알림 종 숫자 — 이미 고침. 재측정으로 확인만.
- **합격:** 360·375·480·768 에서 머리줄 넘침 0 · 2줄 이름 보임 · 1줄 누름 36px 이상·2줄 32px · 로그아웃 상태(전환·종 없음)에서도 깨지지 않음. 360 에서 안 들어가면 로고를 줄인다(버튼을 숨기지 않는다).

### N. 태블릿 사이드바·메뉴 (769~1280)

- N1. **«»» 버튼(2단 칸 펼치기)을 «‹» 옆에서 떼어 낸다.** 지금 위치(위 24px)는 사이드바 접기 «‹» 와 나란하고 화면 제목에 붙어 보인다.
  - ≤1024: **숨긴다.** 이 폭에서 2단 칸(180px)을 고정으로 펼치면 본문이 460px 로 줄어 배치가 무너진다. 하위 메뉴는 N2 의 누름 창으로 연다.
  - 1025 이상: 머리줄 아래 금(사이드바 경계와 머리 밑줄이 만나는 곳, 위에서 약 66px)으로 내리고 32px 로 키운다.
  - 네 버튼(Collapse/Expand Sidebar · Expand/Collapse panel · Open Sidebar)의 이름을 4개 언어로: «메뉴 접기/펼치기» · «하위 메뉴 고정/접기».
- N2. **손가락으로 하위 메뉴에 닿기 — 먼저 잰다.** 코드상 2단 칸이 접힌 상태(≤1280 기본)의 하위 메뉴 창은 «마우스 올리기» 로 열린다. 손가락 기기에서 실제로 어떻게 되는지 확인 안 됨(눌렀을 때 창이 열리고 남는지, 바로 첫 화면으로 가 버리는지).
  - 측정: 역할마다 820·1180 터치 흉내로 하위 메뉴가 있는 1단을 전부 눌러 보고, 2단 항목 전부에 닿는지 · 창이 내용 위에 남는지 기록.
  - 불합격이면 고침(M6): **손가락 입력일 때만**(마우스 올리기가 없는 기기 · 2단 칸 접힘 · 769 이상) 하위 메뉴가 있는 1단을 누르면 **이동하지 않고 하위 메뉴 창을 연다.** 항목을 누르면 이동하고 닫힘, 창 밖을 누르면 닫힘. 마우스 PC 동작은 그대로. (폰 ≤768 의 «누르면 아래로 펼침» 분기와 같은 자리, 같은 모양의 분기 하나.)
  - 합격이면 손대지 않는다.
- N3. **1단 메뉴가 아래로 더 있다는 것이 보이게.** 태블릿 가로(높이 768)에서 사이드바 아래 고정 묶음(Refer & Earn · 도움말 · 매장 전환 · 언어 · 내 정보 ≈ 300px)이 메뉴 13개 중 8개만 남긴다. 줄 경계에서 딱 잘려 «더 있음» 을 알 수 없다.
  - 측정: 1180×820 · 1024×768 · 820×1180 · 768×1024 에서 «보이는 1단 수 / 전체».
  - 고침(순서대로, 앞의 것으로 되면 멈춤): ① 높이 900px 이하에서 아래 묶음의 여백을 줄임(줄 사이 12→6, 안쪽 12→8, 내 정보 카드의 메일 줄 숨김) ② 메뉴 칸 아래 끝에 흐림(더 있음 표시).
  - 매장 전환·내 정보는 계속 아래에 고정(안전장치).

### B. «프린터 미지정» 띠 (`PrinterSetupGapBanner.tsx` — 보호 아님)

Irene 11-12 뜻(«빠진 것을 놓치지 않게»)은 지킨다. 덮지 않게만 바꾼다.
- B1. **≤1024: 한 줄 알약**으로 — `● 프린터 미지정 2곳 ›` (높이 40px, 폭 최대 260px). 누르면 지금의 큰 상자(주방 이름·안내·«1시간 뒤 다시 알림»·«프린터 정하기»)가 열리고, 밖을 누르거나 화면을 옮기면 다시 알약. 알약은 «1시간 뒤» 를 누르기 전엔 계속 보인다.
- B2. **왼쪽 기준 = 본문 칸 왼쪽 끝 + 16** — 사이드바(매장 전환·내 정보)를 덮지 않는다. 본문 칸을 못 찾으면 지금처럼 16.
- B3. 1025 이상: 큰 상자 그대로, 위치만 B2.
- **합격(F8):** 375 일반 화면 · POS 단말 768·1024 · 주방 화면 768 · 발주(아래 Cart 띠) 에서 알약 밑에 누르는 요소 0. 반증 사례 = 지금의 POS 768(결제 줄 왼쪽 버튼이 덮임).

### T. 공용 표 `UI/DataTable.tsx` (POS·주방 화면은 이 부품을 안 쓴다 — 확인함)

**T1. 표 상태(≥1025)를 조밀하게 — 정의만 고침, 쓰는 화면 코드 변경 0**
- 가운데·오른쪽 정렬 칸은 줄바꿈 금지. (이 부품의 정렬 규칙상 가운데 = 날짜·상태, 오른쪽 = 금액 — 원래 짧은 칸이다.)
- 1025~1440 에서 칸 안 여백 16 → 세로 12 · 가로 10.
- 행 버튼 묶음(`DataTableActions`)은 표 상태에서 한 줄(쌓지 않음).
- **효과와 위험:** «보기 싫은 줄바꿈» 이 «표가 칸보다 넓음» 으로 바뀐다 — 이건 잴 수 있다. 넓은 표는 감싸개 안에서 가로로 밀린다(잘리지 않음). ⚠ 11-10 에 버튼 묶음 폭을 넓혔다가 1366 에서 버튼이 숨어 되돌린 일이 있다 → T2 측정이 의무.

**T2. 측정(1100·1180·1280·1366)** — 표마다: 표 폭 > 칸 폭인지 · 가장 높은 줄 높이 · 낱말 중간 줄바꿈 칸.

**T3. 걸린 표의 처방 — 이 순서로, 앞의 것으로 되면 멈춘다**
