#### 1. D1 — 내가 만든 회귀를 되돌린 것
8/22 중복 가드로 소프트 중복(괄호 설명만 다른 변형)을 409 로 막았는데 **프론트가 `force` 를 안 보내**
종이볼 L/M/S 같은 진짜 변형을 등록할 수 없었다. 운영 번들 **234청크 전수** `SIMILAR_EXISTS` 0건으로
확인. 확인 모달 → "Register anyway" → `force:true`. **완전 중복은 force 로도 차단**(운영 실호출 확인).
※ 운영 측 근거 "main.js 0건"은 측정법이 틀렸다 — lazy 청크라 main.js 는 원래 0건. 결론만 맞았다.

#### 2. 빠진 값 표시
판매가 없음=빨강(빠뜨림) / 원가 근거 없음=회색(아직 안 이음). **원가를 경고색으로 안 한 이유**: 운영
754개 전부라 목록이 통째로 붉어져 진짜 문제가 묻힌다. 요약 줄 숫자 클릭 → 그것만 필터, 0 이면 줄 자체
미표시. 공용 `StatusBadge` 사용(로컬 배지 신규 0, 디자인 가드 신규 위반 0).

#### 3. 레시피 없는 상품 = 그 자체가 재고 (핵심)
**확정 모델(Irene): 상품은 둘 중 하나. RA 메뉴·BG 프로덕트 완전 대칭.**
