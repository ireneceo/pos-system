# 운영서버 안전 배포 (v3.0)

운영서버에 안전하게 배포하는 명령어입니다.

---

## 배포 스크립트 v3.0 (개선됨)

### 주요 개선사항
- **sudo 불필요** (nginx reload만 NOPASSWD 설정됨)
- **빠른 배포** (불필요한 단계 제거, 병렬 처리)
- **자동화 지원** (`--auto` 플래그)
- **안전한 롤백**

### 배포 단계

| 단계 | 작업 | 소요시간 |
|------|------|----------|
| 1 | Pre-flight 체크 | ~1s |
| 2 | 백업 생성 | ~3s |
| 3 | 백엔드 코드 동기화 | ~2s |
| 4 | npm install | ~5s |
| 5 | DB 스키마 동기화 | ~2s |
| 6 | 프론트엔드 빌드 | ~60s |
| 7 | 프론트엔드 배포 | ~1s |
| 8 | PM2 재시작 | ~2s |
| 9 | Nginx 리로드 | ~1s |
| 10 | 헬스체크 | ~2s |

**총 예상 시간: ~80초**

---

## 배포 실행

### 자동 배포 (권장)

```bash
/var/www/deploy-production-v3.sh --auto
```

### 대화형 배포

```bash
/var/www/deploy-production-v3.sh
```

### 테스트 (Dry-run)

```bash
/var/www/deploy-production-v3.sh --dry-run
```

```bash

ls -la /var/www/backups/

```

---

## 문제 해결

### 헬스체크 실패

```bash
# 로그 확인
pm2 logs production-backend --lines 50

# 수동 재시작
pm2 restart production-backend
```

### 프론트엔드 문제

```bash
# Nginx 캐시 정리 및 재시작
sudo rm -rf /var/cache/nginx/*
sudo systemctl reload nginx
```

## 관련 파일

- `/var/www/deploy-production-v3.sh` - 배포 스크립트 (v3.0)
- `/var/www/rollback-production.sh` - 롤백 스크립트
- `/var/www/.last-deployed-commit` - 마지막 배포 커밋
- `/var/www/backups/` - 백업 디렉토리
- `/etc/sudoers.d/deploy-permissions` - sudo 권한 설정
