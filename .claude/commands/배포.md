# 운영서버 안전 배포 (v2.0)

운영서버에 안전하게 배포하는 명령어입니다.

---

## 배포 스크립트 개요 (v2.0)

배포 스크립트 `deploy-production.sh`가 자동으로 수행하는 작업:

| 단계 | 작업 | 실패 시 |
|------|------|---------|
| Step 0 | 변경사항 확인 + 배포 승인 | 취소 가능 |
| Step 1 | **개발서버 API 테스트** | 배포 중단 |
| Step 2 | 백업 (.env, 코드, DB) | 배포 중단 |
| Step 3 | Git Pull | 계속 |
| Step 4 | 백엔드 코드 동기화 | 배포 중단 |
| Step 5 | npm install | 배포 중단 |
| Step 6 | DB 스키마 동기화 | 배포 중단 |
| Step 7 | 프론트엔드 빌드 | 배포 중단 |
| Step 8 | 프론트엔드 배포 | 배포 중단 |
| Step 9 | PM2 재시작 | 배포 중단 |
| Step 10 | Nginx 리로드 | 경고 |
| Step 11 | **운영서버 API 테스트** | 롤백 권고 |

---

## 배포 실행

### 1. 배포 전 개발서버 테스트 (권장)

배포 스크립트가 API 테스트를 자동 수행하지만, UI 테스트는 수동으로 확인:

```bash
# 개발서버 접속하여 확인
https://dev.purplehere.com
```

확인 항목:
- [ ] POS 터미널 정상 동작
- [ ] 모바일 QR 주문 정상 동작
- [ ] 이번 배포에서 수정한 기능 정상 동작

### 2. 배포 실행

```bash
echo '7u7LnxNr' | sudo -S /var/www/deploy-production.sh
```

스크립트가 자동으로:
1. 변경사항 목록 표시 → 승인 요청
2. 개발서버 API 테스트 (실패 시 중단)
3. 전체 백업 수행 (코드 + DB)
4. 코드 동기화 및 빌드
5. 운영서버 API 테스트 (실패 시 롤백 권고)

### 3. 배포 후 확인

```bash
# 자동 테스트 외 수동 확인
https://purplehere.com

# POS 터미널
https://purplehere.com/restaurant/8/pos

# 모바일 QR
https://purplehere.com/mobile/[store-slug]
```

## 롤백

문제 발생 시 즉시 롤백:

```bash
# 사용 가능한 백업 목록 확인
sudo /var/www/rollback-production.sh

# 특정 백업으로 롤백
sudo /var/www/rollback-production.sh [TIMESTAMP]
```

롤백 스크립트가 복원하는 항목:
- 백엔드 코드
- 프론트엔드 빌드
- 데이터베이스 (선택)

---

## 백업 구조

```
/var/www/backups/[TIMESTAMP]/
├── .env.backup                      # 환경변수
├── production-backend.backup/       # 백엔드 코드 전체
├── production-frontend-build.backup/ # 프론트엔드 빌드
└── db_backup_[TIMESTAMP].sql.gz     # 데이터베이스
```

## 문제 해결

### API 테스트 실패 시

```bash
# 개발서버 로그 확인
pm2 logs dev-backend --lines 50

# 개발서버 재시작
pm2 restart dev-backend
```

### 배포 후 문제 발생 시

```bash
# 1. 즉시 롤백
sudo /var/www/rollback-production.sh [TIMESTAMP]

# 2. 로그 확인
pm2 logs production-backend --lines 100

# 3. 수동 재시작 (필요시)
pm2 restart production-backend
```

### 헬스체크 실패 시

```bash
# 서버 상태 확인
pm2 list

# 수동 헬스체크
curl http://localhost:3002/api/health

# 로그 확인
pm2 logs production-backend --err --lines 50
```

## 관련 파일

- `/var/www/deploy-production.sh` - 배포 스크립트 (v2.0)
- `/var/www/rollback-production.sh` - 롤백 스크립트 (v2.0)
- `/var/www/.last-deployed-commit` - 마지막 배포 커밋
- `/var/www/backups/` - 백업 디렉토리
