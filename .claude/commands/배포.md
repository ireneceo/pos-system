# 운영서버 안전 배포

운영서버에 안전하게 배포하는 명령어입니다.

---

## 배포 프로세스

### 1단계: 사전 확인
다음 항목을 확인해주세요:

1. **개발 서버 빌드 확인**
   ```bash
   cd /var/www/dev-frontend && npm run build
   ```
   - 빌드 에러가 없는지 확인

2. **개발 DB vs 운영 DB 스키마 비교**
   - 새로운 테이블이나 컬럼이 추가되었는지 확인
   - `sync-database.js`가 처리할 수 있는 변경인지 확인
   - 위험한 변경(컬럼 삭제, 타입 변경 등)이 있으면 경고

3. **Git 상태 확인**
   ```bash
   cd /var/www && git status
   ```
   - 커밋되지 않은 변경사항이 있는지 확인

### 2단계: 변경사항 커밋 (필요시)
커밋되지 않은 변경사항이 있다면:
```bash
git add -A && git commit -m "chore: Auto-commit before deployment"
```

### 3단계: 배포 실행
배포 스크립트 실행:
```bash
sudo /var/www/deploy-production.sh
```

### 4단계: 배포 후 확인
1. https://purplehere.com 접속 확인
2. 브라우저에서 Ctrl+Shift+R (강력 새로고침)
3. POS Terminal 기능 테스트
4. 모바일 오더 테스트

---

## 주의사항

- **운영 중인 서비스**이므로 배포 전 반드시 빌드 확인
- DB 스키마 변경 시 특히 주의 (데이터 손실 가능성)
- 문제 발생 시 롤백: `sudo /var/www/rollback-production.sh [타임스탬프]`

---

## 관련 파일
- `/var/www/DEPLOYMENT.md` - 상세 배포 가이드
- `/var/www/deploy-production.sh` - 배포 스크립트
- `/var/www/rollback-production.sh` - 롤백 스크립트
