# 개발 완료 명령어

이 명령어는 개발 세션을 마무리할 때 사용합니다.

---

## Claude 필수 수행 사항

**이 명령어가 실행되면 Claude는 반드시 다음을 순서대로 수행해야 합니다:**

### 1단계: 오늘 개발 내용 파악

**현재 세션에서 수행한 작업들을 분석:**
- 수정된 파일들 확인 (git status, git diff)
- 새로 추가된 기능
- 버그 수정 내역
- 설정 변경 사항

### 2단계: 문서 업데이트

**다음 파일들을 최신 상태로 업데이트:**

1. **DEVELOPMENT_PLAN.md** (`/var/www/DEVELOPMENT_PLAN.md`)
   - "완료된 작업" 섹션에 오늘 완료한 작업 추가
   - "진행 중인 작업" 섹션 업데이트
   - "예정된 작업" 섹션 필요시 수정
   - 최종 업데이트 날짜 변경

2. **FEATURE_BASED_SUBSCRIPTION_PLAN.md** (`/var/www/docs/FEATURE_BASED_SUBSCRIPTION_PLAN.md`)
   - Phase별 진행 상태 업데이트 (체크박스 표시)
   - 새로 구현된 기능 표시

3. **기타 관련 문서** (`/var/www/docs/` 폴더)
   - 새 기능 관련 문서가 있으면 업데이트
   - 필요시 새 문서 생성

### 3단계: Git 커밋 및 푸시

```bash
# 1. 변경사항 확인
cd /var/www
git status
git diff --stat

# 2. 모든 변경사항 스테이징
git add -A

# 3. 커밋 메시지 작성 (오늘 작업 요약)
git commit -m "chore: Auto-commit $(date +'%Y-%m-%d %H:%M:%S')

[오늘 작업 요약]
- 주요 변경사항 1
- 주요 변경사항 2
- ...

🤖 Generated with Claude Code"

# 4. 원격 저장소에 푸시
git push origin main
```

### 4단계: 작업 완료 보고

사용자에게 다음 정보를 요약 보고:
- 오늘 완료한 작업 목록
- 업데이트된 문서 목록
- Git 커밋 해시
- 다음 세션에서 이어서 할 작업 (있다면)

### 5단계: 운영 배포 전 체크리스트 (배포 시에만)

**`/배포` 실행 전 반드시 확인 (1분 체크):**

```
[ ] DB 스키마 변경 없음 (또는 마이그레이션 준비됨)
[ ] .env 변경 없음 (또는 운영 .env 업데이트됨)
[ ] 롤백 명령어 확인: ./rollback-production.sh [TIMESTAMP]
[ ] 개발서버 테스트 완료
[ ] 빌드 에러 없음
[ ] 민감정보 커밋 여부 확인: git diff --cached | grep -i password
```

**체크리스트 미통과 시 배포 금지**

## 업데이트 대상 파일 목록

| 파일 경로 | 용도 |
|-----------|------|
| `/var/www/DEVELOPMENT_PLAN.md` | 개발 진행 현황 (메인) |
| `/var/www/docs/FEATURE_BASED_SUBSCRIPTION_PLAN.md` | 기능별 구현 계획 |
| `/var/www/docs/ROLES_AND_PERMISSIONS.md` | 권한 시스템 (필요시) |

| `/var/www/docs/RECIPE_MANAGEMENT_SYSTEM.md` | 레시피 시스템 (필요시) |
| `/var/www/.claude/commands/개발시작.md` | 개발 시작 가이드 (필요시) |

## 커밋 메시지 형식

```
chore: Auto-commit YYYY-MM-DD HH:MM:SS

[작업 요약]
- feat: 새 기능 추가
- fix: 버그 수정
- refactor: 코드 리팩토링
- docs: 문서 업데이트
- style: UI/스타일 변경

[변경된 주요 파일]
- path/to/file1.tsx
- path/to/file2.js

🤖 Generated with Claude Code
```

---

## 주의사항

1. **운영서버 배포는 별도** - 이 명령어는 문서 업데이트와 Git 백업만 수행
2. **민감한 정보 제외** - .env 파일 등은 커밋하지 않음 (.gitignore 확인)
3. **충돌 발생 시** - 사용자에게 알리고 해결 방법 안내

## 실행 예시

```
사용자: /개발완료

Claude 응답:
1. 오늘 개발 내용 분석 중...
   - Reports 페이지 Month 필터 그래프 버그 수정
   - 환경변수 관리 개선 (SUDO_PASSWORD)

2. 문서 업데이트 중...
   - DEVELOPMENT_PLAN.md 업데이트 완료

3. Git 커밋 및 푸시 중...
   - 커밋: abc1234
   - 푸시 완료

4. 작업 완료 보고:
   ✅ 오늘 완료: Reports 필터 버그 수정, 환경변수 정리
   📝 문서 업데이트: DEVELOPMENT_PLAN.md
   🔄 Git 백업: abc1234 (main)
   📋 다음 작업: 없음 (또는 다음 예정 작업)
```
