# /블로그발행 — 블로그 초안을 발행 상태로 전환

**호출**: `/블로그발행 <translation_group_id>` 또는 `/블로그발행 <content_id>` (단일 언어만 발행)

---

## ★ 사용자 환경 / 권한 모델

이 스킬은 **어떤 OS 사용자(irene/lua/...)가 실행해도 동일하게 작동**한다. 모든 작업은 **HTTP API 호출**만 사용. **`.env` / `require('dotenv')` / `require('./models/...')` 절대 금지** — `.env`는 `irene:irene 600`이라 다른 OS 사용자는 못 읽고, application-level RBAC는 SA 토큰만으로 통과한다.

자격증명은 `~/.purple-pos/creds.json` 또는 `PURPLE_USER`/`PURPLE_PASS`. 부재 시 스크립트가 명확히 fail 하고 종료한다 — 우회 금지.

---

## Claude가 수행할 작업

### 0단계: SA 토큰 발급 (모든 단계 공통)

```bash
TOKEN=$(node /var/www/dev-backend/scripts/sa-token.js) || exit 1
API=http://localhost:3001/api
```

이후 모든 admin 호출에 `Authorization: Bearer $TOKEN` 사용.

### 1단계: 대상 컨텐츠 식별

`<arg>`가 group인지 single인지 모르는 상태로 둘 다 시도.

```bash
# group 후보 (해당 translation_group_id 의 모든 row)
curl -s -H "Authorization: Bearer $TOKEN" \
  "$API/contents?translation_group_id=<arg>" | tee /tmp/blog-rows.json
```

`data` 배열이 비었으면 single content 후보로 fallback:

```bash
curl -s -H "Authorization: Bearer $TOKEN" "$API/contents/<arg>"
```

각 row의 `id / language / title / status` 출력. status=published 인 row는 이미 발행된 상태이므로 skip.

### 2단계: status='published' 전환

각 draft row 마다:

```bash
curl -s -X PUT -H "Authorization: Bearer $TOKEN" \
  "$API/contents/<id>/publish"
```

응답 success 확인. 실패 시 즉시 보고하고 멈춤 (재시도/우회 금지).

### 3단계: 검증 — 공개 URL 응답 확인

```bash
for slug in "<en-slug>" "<ms-slug>" "<zh-slug>"; do
  curl -s "$API/contents/public/blog/$slug" | head -c 400
  echo
done
```

각 응답에서 `post.status === 'published'` 인지 확인.

### 4단계: Irene 보고

```
✓ 발행 완료
translation_group_id: <N>

공개 URL (dev):
  - EN: https://dev.purplehere.com/blog/<en-slug>
  - MS: https://dev.purplehere.com/blog/<ms-slug>
  - ZH: https://dev.purplehere.com/blog/<zh-slug>

운영 반영: /배포 (콘텐츠 sync 자동 포함)
```

## 절대 금지

- ❌ `cd /var/www/dev-backend && node -e "require('dotenv').config();..."` 같은 직접 DB 접근
- ❌ `cat insert-blog.js | node` 형태의 임시 발행 스크립트 생성
- ❌ "irene 사용자로 실행해주세요" 식의 핸드오프 — sa-token.js + curl 패턴은 lua 사용자도 그대로 실행 가능
- ❌ 자격증명 부족 시 우회로 새 스크립트 만들기 — 자격증명 부재 메시지를 그대로 사용자에게 전달하고 멈춘다

자격증명 / 권한 부족은 **사용자가 자기 SA 자격증명을 `~/.purple-pos/creds.json`에 저장**하는 것으로 해결한다. 코드/스크립트로 우회 X.
