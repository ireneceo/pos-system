# /블로그캘린더 — 발행 캘린더 관리 + 자동 슬롯 채움

**호출**: `/블로그캘린더` 또는 `/블로그캘린더 weeks=8` (향후 8주 표시)

---

## ★ 사용자 환경 / 권한 모델

`require('dotenv')` / `require('./models/...')` 같은 DB 직접 접근은 **백엔드 운영 사용자(irene) 세션에서만 작동** (`.env` 권한 600). 다른 OS 사용자(lua 등)는 **HTTP API 호출**만 사용:

```bash
TOKEN=$(node /var/www/dev-backend/scripts/sa-token.js) || exit 1
curl -s -H "Authorization: Bearer $TOKEN" http://localhost:3001/api/contents
```

자격증명: `~/.purple-pos/creds.json` 또는 `PURPLE_USER`/`PURPLE_PASS`. 자격증명/권한 부족 → 우회 금지, 메시지 그대로 사용자에게 전달하고 종료.

## Claude가 수행할 작업

### 1단계: 향후 N주 발행 예정 집계

```bash
cd /var/www/dev-backend && node -e "
require('dotenv').config();
const Content = require('./models/Content');
const { Op } = require('sequelize');
(async () => {
  const start = new Date();
  start.setHours(0,0,0,0);
  const end = new Date(start.getTime() + <weeks>*7*24*60*60*1000);

  const scheduled = await Content.findAll({
    where: {
      type: 'blog',
      status: 'draft',
      created_at: { [Op.gte]: start }
    },
    attributes: ['id','translation_group_id','language','title','content_tier','target_persona','created_at']
  });

  console.log('Draft posts waiting for publish:', scheduled.length);
  scheduled.forEach(s => console.log(' -', s.created_at.toISOString().substring(0,10), '|', s.language, '|', s.content_tier || '?', '|', s.title.substring(0,50)));
  process.exit(0);
})();
"
```

### 2단계: 주간 권장 리듬과 현재 상태 비교

권장:
- 주 3편 원글 × 3언어 = **주 9 row**
- 월 13 원글 × 3 = **월 39 row**

현재 발행 리듬 집계 (최근 4주):
```bash
cd /var/www/dev-backend && node -e "
const Content = require('./models/Content');
const { Op } = require('sequelize');
(async () => {
  const now = new Date();
  for (let w = 0; w < 4; w++) {
    const end = new Date(now.getTime() - w*7*24*60*60*1000);
    const start = new Date(end.getTime() - 7*24*60*60*1000);
    const n = await Content.count({ where: { type: 'blog', status: 'published', published_at: { [Op.gte]: start, [Op.lt]: end } } });
    console.log('Week -' + w + ' (' + start.toISOString().substring(0,10) + '):', n, 'published');
  }
  process.exit(0);
})();
"
```

### 3단계: 빈 슬롯 식별 + 자동 채움 제안

향후 4주 각 슬롯:
```
Week 1 (Apr 22-28):
  월 22: [Tactical / RO / TOFU] ✗ 미배정
  화 23: [Cluster / FCO / MOFU] ✗ 미배정
  수 24: [Pillar 또는 CaseStudy] ✗ 미배정
  목 25: [Tactical / BG / MOFU] ✗ 미배정
  금 26: [NewsJack] ✗ 미배정
Week 2 (Apr 29-May 5): ...
```

빈 슬롯이 있으면:
- 가장 최근 `/블로그리서치` 결과 뱅크에서 자동 추천
- 각 슬롯에 대해 다음 실행 제안:
  ```
  /블로그초안 topic="<추천 주제>" persona=<...> funnel=<...> tier=<...>
  ```

## Cron 자동화 (선택 기능)

운영 안정화 후 cron 연동 가능:
- 매주 일요일 18:00 → `/블로그캘린더 weeks=1` 자동 실행
- 빈 슬롯이 있으면 `/블로그리서치` + `/블로그초안` 연쇄 실행
- Irene 에게 draft 3편 알림 → 아침에 승인하면 자동 발행

ScheduleWakeup 또는 CronCreate 로 구현 가능 (별도 설정 필요).
