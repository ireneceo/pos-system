# 세션 저장 명령어

현재 Claude Code 대화 내용과 개발 히스토리를 저장합니다.

## 실행 단계

### 1. 현재 세션 상태 저장

`/var/www/.claude/session-state.md` 파일을 업데이트합니다:

```markdown
## 현재 작업 상태
**마지막 업데이트:** [현재 날짜시간 UTC]
**작업 상태:** [진행중/완료]

### 진행 중인 작업
- [현재 진행 중인 작업 목록]

### 완료된 작업 (이번 세션)
- [이번 세션에서 완료한 작업들]
- [각 작업에 대한 간단한 설명]
- [수정한 주요 파일 목록]

### 다음 확정 작업
- [Irene 이 명시 지시한 다음 작업만. 없으면 "없음 — 지시 대기"]

### 후속 후보 (아이디어 메모, 확정 X)
> /개발시작 자동 추천 대상 아님. 다음 사이클 결정은 Irene 지시 기준.
- [known issue / 아이디어]

### 주요 변경사항
- [중요한 코드 변경 요약]
- [설정 변경 사항]
- [해결한 버그/이슈]
```

> **단일 소스 규칙**: 위 `진행 중인 작업` / `다음 확정 작업` / `후속 후보` 는 `/개발시작` 이 읽는 **단일 소스**다. 매번 이번 대화 기준으로 **새로 쓴다**(안 바뀌었어도 그대로 다시 적기 — 침묵 상속 금지). `DEVELOPMENT_PLAN.md` 는 완료 아카이브 전용이므로 "다음 할 일" 을 거기서 끌어오지 말 것.

### 2. Git 상태 기록

현재 Git 상태도 함께 기록합니다:
- 수정된 파일 목록
- 커밋되지 않은 변경사항
- 최근 커밋 해시

### 3. 저장 완료 알림

저장 완료 후 사용자에게 알립니다:
- 저장된 위치
- 저장된 내용 요약
- 복구 방법 안내

## 복구 방법

새 세션에서 아래 내용을 입력하면 이어서 작업 가능:

```
이전 세션 이어서 작업하고 싶어.
/var/www/.claude/session-state.md 읽어줘.
```

## 주의사항

- 이 명령어는 파일에 저장하는 것이므로, 서버가 재시작되어도 유지됩니다
- 민감한 정보(비밀번호, API 키 등)는 저장하지 않습니다
- Git 커밋과는 별개입니다 (코드 변경은 별도로 커밋 필요)
