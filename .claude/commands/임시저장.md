# 임시저장 — Clear 전 빠른 저장

**목적:** `/clear` 직전에 **30초 이내**로 현재 상태를 저장하고 바로 이어서 작업할 수 있게 준비.

`/저장` 과 다른 점: 11단계 체크리스트 건너뛰고 **핵심 3가지만** 처리.

---

## Claude 필수 수행 (단순 · 신속)

### 1. Git 자동 커밋 (변경사항 있으면)

```bash
cd /var/www && git status --short
```

**변경사항 있으면:**
```bash
cd /var/www && git add -A && git commit -m "$(cat <<'EOF'
chore: 세션 중간 저장 - [한 줄 작업 요약]

Co-Authored-By: Claude Opus 4.7 (1M context) <noreply@anthropic.com>
EOF
)"
```

- 커밋 메시지는 **한 줄 요약만** (복잡한 본문 X)
- 변경사항이 없으면 이 단계 건너뜀
- **push는 하지 않음** — `/배포` 명령 없이는 절대 push 금지 (CLAUDE.md 규칙)

**변경사항 없으면:** "커밋 스킵 — 변경 없음"

---

`/var/www/.claude/session-state.md` 에 **최소 필수 정보만** 덮어쓰기:

## 📋 작업계획 (단일 소스 — 매번 갱신, 침묵 상속 금지)

> 이 블록이 `/개발시작` 이 분기에 읽는 **단일 소스**다. `임시저장` 도 매번 **다시 쓴다**. (예전엔 "유효하면 그대로 유지" 라서 옛 항목이 눌러앉아 `/개발시작` 이 헌 작업을 안내하는 사고가 났음 — 그 루프홀 제거.)

`### 진행 중인 작업` / `### 다음 확정 작업` / `### 후속 후보` 세 줄을 **이번 대화 기준으로 매번 새로 쓴다**:
- `### 다음 확정 작업`: 이번 대화에서 Irene 이 명시 지시한 다음 작업만. 안 바뀌었어도 **그대로 다시 적는다**(빈칸/생략 금지). 지시 없으면 `없음 — 지시 대기`.
- `### 후속 후보 (아이디어 메모, 확정 X)`: known issue/아이디어. `/개발시작` 자동 추천 대상 아님 명시.
- DEVELOPMENT_PLAN.md 는 **완료 아카이브 전용** — 거기 미완 항목을 멋대로 "다음 확정 작업" 으로 올리지 말 것(확정은 Irene 지시만).

## 절대 하지 말 것

- ❌ 헬스체크 돌리지 말 것 (오래 걸림)
- ❌ 빌드 돌리지 말 것
- ❌ pm2 restart 하지 말 것
- ❌ **git push 하지 말 것** — 운영 배포는 `/배포` 명령 전용 (CLAUDE.md 규칙)
- ❌ 11단계 체크리스트 전부 돌리지 말 것 (그건 `/저장` 의 역할)
- ❌ DEVELOPMENT_PLAN.md 히스토리 섹션 추가하지 말 것 (그건 `/개발완료` 의 역할)
- ❌ Memory 파일 업데이트하지 말 것 (그건 `/개발완료` 의 역할)
- ❌ 장황한 보고하지 말 것
- ❌ 사용자 피드백 기다리지 말 것 — 3단계 끝나면 바로 "완료" 알리기

## `/저장` vs `/임시저장` vs `/개발완료` 비교

| 명령어 | 소요 | 커밋 | state 상세 | DEV_PLAN 히스토리 | Memory | 헬스체크 | 백업 |
|---|---|:-:|---|:-:|:-:|:-:|:-:|
| `/임시저장` | 30초 | 자동 | 핵심만 | ❌ | ❌ | ❌ | ❌ |
| `/저장` | 2~3분 | 자동 | 전체 | ❌ | ❌ | ❌ | ❌ |
| `/개발완료` | 5~10분 | 자동 | 전체 | ✅ | ✅ | ✅ | ✅ |

**일상 workflow:**
- 잠깐 자리 비울 때 → `/임시저장`
- 세션 끝날 때 (가벼운) → `/저장`
- 하루 끝 · 마일스톤 · 배포 직전 → `/개발완료`

## PurpleHere 전용 주의사항 (PlanQ와 차이)

- **Push 금지**: PlanQ는 commit+push 자동, PurpleHere는 **commit만** (운영 배포는 `/배포` 경로로)
- **경로**: `/var/www` (PlanQ는 `/opt/planq`)
- **session-state 위치**: `/var/www/.claude/session-state.md`
