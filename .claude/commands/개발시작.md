## Claude 필수 수행 사항 (맨 먼저 실행)

**이 명령어가 실행되면 Claude는 반드시 다음을 순서대로 수행해야 합니다:**

### 0단계: 이전 세션 상태 확인
```
Read 도구로 다음 파일 읽기:
- /var/www/.claude/session-state.md
```
- 이전에 진행 중이던 작업이 있는지 확인
- 있으면 사용자에게 "이전에 [작업명] 진행 중이었습니다. 이어서 할까요?" 질문

### 1단계: 프로젝트 구조 파악 (Bash로 실행)
```bash
# 핵심 모델 목록 (DB 스키마 이해)
ls /var/www/dev-backend/models/

# 핵심 라우트 목록 (API 패턴 이해)
ls /var/www/dev-backend/routes/

# 프론트 페이지 구조
ls /var/www/dev-frontend/src/pages/

# 공통 컴포넌트 목록
ls /var/www/dev-frontend/src/components/
```

### 2단계: 핵심 문서 읽기
```
Read 도구로 다음 파일들 읽기:
- /var/www/docs/FEATURE_BASED_SUBSCRIPTION_PLAN.md (개발 로드맵)
- /var/www/DEVELOPMENT_PLAN.md (작업 히스토리, 앞부분 500줄)
```

### 3단계: 현황 파악 및 다음 작업 안내
- 완료된 Phase 목록 확인
- 진행 중인 작업 확인
- **다음 개발할 기능을 구체적으로 안내**
- 관련 설계 문서 경로 제시
- 참조해야 할 기존 코드 경로 제시

## 핵심 규칙 요약

### 절대 금지
- **운영서버 직접 수정 금지** → 배포 스크립트만 사용
- **샘플/가짜 데이터 사용 금지** → 모든 데이터는 DB에서 API로
- **alert(), toast.success() 금지** → 성공 시 모달 닫고 리프레시
- **npm run build 직접 사용 금지** → `npm run build:dev` 사용

### 개발 워크플로우
```bash
# 1. 개발서버에서 작업
/var/www/dev-backend/
/var/www/dev-frontend/

# 2. DB 스키마 변경 시
cd /var/www/dev-backend && node sync-database.js
pm2 restart dev-backend

# 3. 프론트엔드 빌드
cd /var/www/dev-frontend && npm run build:dev

# 4. 운영 배포 (/배포 명령어로만)
/var/www/deploy-production.sh
```

### API 응답 형식
```javascript
// 성공
res.json({ success: true, data: result });

// 실패
res.status(400).json({ success: false, message: 'Error message' });
```
