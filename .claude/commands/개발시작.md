# 개발 시작하기

한국어로 "개발시작" 명령어 - `/dev-start` 와 동일한 기능입니다.

Purple POS 시스템의 전체 컨텍스트를 로드하고 다음 작업을 안내합니다.

---

## 🎯 이 명령어가 하는 일

1. **실제 개발 계획 확인** - FEATURE_BASED_SUBSCRIPTION_PLAN.md
2. **최근 작업 히스토리** - DEVELOPMENT_PLAN.md
3. **권한 시스템** - ROLES_AND_PERMISSIONS.md
4. **모든 Docs 문서** 읽기
5. **Git 상태** 확인
6. **명확한 현황 보고** 및 다음 작업 제안

---

## 📋 읽는 문서들

### 필수 문서 (순서대로)
1. `/var/www/docs/FEATURE_BASED_SUBSCRIPTION_PLAN.md` ⭐ 가장 중요
2. `/var/www/DEVELOPMENT_PLAN.md`
3. `/var/www/docs/ROLES_AND_PERMISSIONS.md`
4. `/var/www/docs/` 폴더의 모든 .md 파일
5. `/var/www/WORKFLOW-GUIDE.md` (있는 경우)

---

- ✅ Phase 1: 모듈 선택 시스템 (완료)
