# /글쓰기 — 블로그 글쓰기 전체 파이프라인 (트렌드+키워드 리서치 → 승인 → 3언어 생성 → 발행 → 관리자 알림)

**목적**: Irene이 `/글쓰기` 한 번 치면 엔드투엔드 — 탁월한 마케팅 위주 주제 발굴 + 고품질 3언어 콘텐츠 생성 + 발행 + 시스템 관리자 이메일 알림까지.

**호출**: `/글쓰기` (인자 없음)

**권장 주기**: 주 2-3회 (월/수/금 오전 권장)

---

## 📋 전체 흐름 (Claude가 자동 수행)

```
1. 트렌드 리서치 (WebSearch)
     ↓
2. 키워드 수요 분석 (타겟 SEO + AEO)
     ↓
3. 고객 대화 DB에서 실제 니즈 추출
     ↓
4. 주제 3건 제안 → Irene 선택
     ↓
5. 선택된 주제로 3언어 풀 생성
   - 블로그 본문 (5단계 광고 구조 + 후킹)
   - video_prompt (AI 영상 생성용)
   - social_post (title + body + hashtags)
   - SEO/AEO 메타
     ↓
6. bulk API로 DB 발행 (status=published)
     ↓
7. System Admin 이메일 알림 발송
   (발행된 URL + 배포 가이드)
     ↓
8. Irene에게 결과 보고
```

## 1단계: 트렌드 리서치 (탁월한 마케팅 기준)

WebSearch 쿼리 우선순위:

### A. 검색 수요 트렌드 (SEO 중심)
```
"restaurant POS" malaysia 2026 trends
"foodcourt management" software 2026
"franchise operations" tools
"restaurant marketing" 2026 strategies
"food delivery" trends southeast asia
```

각 검색 결과의 **Google Trends / AnswerThePublic / People Also Ask** 시그널 분석:
- 상승 중인 키워드 → 시장 우위 기회
- "how to" / "best" / "vs" 류 질문 → 높은 구매 의도

### B. 업계 뉴스 (News-jack 가능성)
```
"restaurant regulation Malaysia" 2026
"food court news" Asia
"QR ordering mandatory" Singapore Malaysia
"AI restaurant" trends
```

최근 3개월 이내 기사 3-5개 요약 → PurpleHere 관점 덧붙일 수 있는 것 추출.

### C. AEO (Answer Engine Optimization) 질문 발굴
```
ChatGPT/Perplexity가 답하는 질문들:
- "how to reduce food cost in restaurant"
- "best POS for small restaurant"
- "foodcourt tenant contract template"
- "restaurant franchise startup cost malaysia"
```
→ PurpleHere가 "답변"을 소유할 수 있는 질문 선정.

### D. 경쟁사 최근 블로그 체크
```
site:toasttab.com/blog 2026
site:squareup.com/us/en/press/restaurant trends
site:lightspeedhq.com/blog restaurant
site:tapos.com.my/blog (로컬 경쟁)
```
→ 경쟁사 다루지 않은 **공백 주제** 찾기.

## 2단계: 내부 고객 대화 DB에서 실제 니즈

```bash
cd /var/www/dev-backend && node -e "
const SupportTicket = require('./models/SupportTicket');
const ContactInquiry = require('./models/ContactInquiry');
const OperationTicket = require('./models/OperationTicket');
(async () => {
  const tickets = await SupportTicket.findAll({ limit: 30, order: [['createdAt','DESC']] });
  const inquiries = await ContactInquiry.findAll({ limit: 30 });
  const ops = await OperationTicket.findAll({ limit: 30 });
  console.log('=== Support Tickets ===');
  tickets.forEach(t => console.log('  [' + t.category + '] ' + t.subject));
  console.log('\\n=== Contact Inquiries ===');
  inquiries.forEach(i => console.log('  [' + i.inquiry_type + '] ' + (i.message||'').substring(0,100)));
  console.log('\\n=== Operation Tickets ===');
  ops.forEach(o => console.log('  [' + o.category + '] ' + o.subject));
  process.exit(0);
})();
"
```

반복되는 키워드/상황 3-5개 추출 → 주제 뱅크에 반영.

## 3단계: 마케팅 가치 기준으로 주제 3건 제안

각 주제 평가 스코어 (0-10):
| 차원 | 설명 |
|------|------|
| **검색 수요** | 월간 검색량 추정 (WebSearch 결과의 노출도) |
| **경쟁 공백** | 경쟁사가 안 다루거나 약하게 다룬 주제 (+ 점수) |
| **PurpleHere 적합도** | 우리 기능이 실제 해결책인가 (높을수록 전환율 ↑) |
| **현지성** | 말레이시아 / 화교권 특화 관점 (지역 SEO 이점) |
| **AEO 가능성** | 질문형 + 숫자/팩트 기반 답변 가능 |

총점 상위 3건 출력:

```
📝 이번 주 추천 주제 (총점 순)

1. [총점 42/50] Personas: restaurant_owner / Problem: customer_experience
   제목: "QR 주문 도입 6개월, 매출은 올랐는데 왜 재방문율은 떨어졌을까?"
   근거: 
     - GPT/Perplexity가 자주 답하는 질문 (AEO 우위)
     - 경쟁사(Toast/Square) 미다룸
     - PurpleHere QR 기능 + Customer CRM 연결 가능
     - 최근 ContactInquiry에서 2건 유사 질문

2. [총점 38/50] Personas: foodcourt_operator / Problem: data_decisions
   제목: ...

3. [총점 35/50] Personas: brand_general / Problem: management
   제목: ...

어느 주제로 쓸까요? (1/2/3 중 선택 또는 "다른 거")
```

Irene 응답 대기 → 선택된 주제로 4단계 진입.

## 4단계: 3언어 풀 콘텐츠 생성 (5단계 광고 구조)

`/블로그-초안` 커맨드의 5단계 구조 + 후킹 7기법 + 다포맷 그대로 적용:

### 각 언어마다
- **블로그 본문** (800-1000 words, tactical 기준)
  - TL;DR 상단 박스
  - 5단계: 공감 → 문제 → 해결 → 증거 → CTA
  - H2 질문형 (AEO)
  - 외부 링크 2개 + 내부 링크 2개
  - Focus keyword 자연 반복
- **video_prompt** (15-28s, 9:16, 썸네일=첫 프레임)
- **social_post** { title, body, hashtags[8-10] }
- **SEO/AEO 메타** (seo_title ≤70자, seo_description ≤160자, ai_summary, seo_keywords)

### 태그 자동 부여
- target_persona: 선택 주제에서 결정됨
- problem_category: 선택 주제에서 결정됨
- funnel_stage: 주로 MOFU (검토 단계)
- content_tier: tactical (주간 리듬)

### 다국어 현지화 (단순 번역 금지)
- **EN**: 비즈니스 / 팩트 / 국제적 / RM 화폐 / Sunway·Pavilion·KLCC
- **MS**: 친근 / 공동체 / 라마단·하리라야 시즌 / 할랄 고려
- **ZH**: 간결 / 효율 / ROI 강조 / 차이나타운·호커센터 / 화교 프랜차이즈

## 5단계: bulk API 발행

```bash
POST /api/contents/bulk
{
  "type": "blog",
  "category_id": 6,  // guides (기본), 또는 주제 타입에 따라
  "target_persona": "<persona>",
  "problem_category": "<problem>",
  "funnel_stage": "MOFU",
  "content_tier": "tactical",
  "status": "published",
  "translations": { en: {...}, ms: {...}, zh: {...} }
}
```

**주의**:
- seo_description **반드시 160자 이하**
- content는 longtext라 제한 없지만 HTML 문법 정확
- 각 언어 slug는 현지어 기반

발행 완료 후 `translation_group_id` 반환.

## 품질 체크리스트 (자체 검증 — 발행 전)

### 마케팅 구조
- [ ] 첫 문장이 상품 설명이 아닌 공감/질문
- [ ] 5단계 순서 정확 (공감→문제→해결→증거→CTA)
- [ ] CTA에 **"지금"** 포함
- [ ] 제목에 후킹 기법 1개 이상 적용

### SEO/AEO
- [ ] H2는 질문형
- [ ] TL;DR 박스 상단 (핵심 숫자 포함)
- [ ] ai_summary 2-3 문장
- [ ] focus keyword 제목/첫문단/H2/본문 반복
- [ ] 외부 링크 2개 (공식 출처 — DOSM, MATRADE 등)

### 다국어
- [ ] MS/ZH 는 단순 번역 X (문화/예시/CTA 현지화)
- [ ] slug 3개 언어별 구별
- [ ] seo_description 3개 언어 모두 160자 이하

### 다포맷
- [ ] video_prompt: scene breakdown + 썸네일 = first frame 명시
- [ ] social_post: title/body/hashtags 3종 모두 존재
- [ ] hashtags 8-10개 이내

### DB
- [ ] target_persona / problem_category / funnel_stage / content_tier 모두 설정

## 주의사항

- **한 글 = 한 persona + 한 problem + 한 funnel**. 섞으면 메시지 흐려짐
- **PurpleHere 실재 기능만 언급** (DB AddonModule 목록 참조)
- 경쟁사 직접 비교 금지
- 광고처럼 읽히지 말고 **콘텐츠로** 읽히게 — 해결책 중심
- 숫자는 일반화된 추정치라도 "업계 평균" 맥락 명시
